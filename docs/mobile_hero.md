# Mobile Hero Presentation

On screens up to 820px wide, PRISM keeps the full product hero visible at the top of the application while preserving the existing hamburger/sidebar drawer and bottom analysis dock.

The mobile hero includes the enterprise reporting/data-strategy eyebrow, primary value proposition, explanatory copy, and runtime status pills. It is intentionally non-collapsible on mobile so first-time visitors see the product context before analytical cards.
